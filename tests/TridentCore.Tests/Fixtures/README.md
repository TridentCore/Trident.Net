# Launch metadata fixtures

These fixtures are stored snapshots and tests do not fetch metadata or launch Minecraft.

- `fabric-0.16.14.json`: https://meta.prismlauncher.org/v1/net.fabricmc.fabric-loader/0.16.14.json
- `forge-47.4.0.json`: https://meta.prismlauncher.org/v1/net.minecraftforge/47.4.0.json
- `gtnh-minecraft.json`: https://github.com/GTNewHorizons/lwjgl3ify/blob/master/prism-libraries/patches/net.minecraft.json
- `gtnh-forge.json`: https://github.com/GTNewHorizons/lwjgl3ify/blob/master/prism-libraries/patches/net.minecraftforge.json

The GTNH fixtures cover the Java 17+ component templates supplied by lwjgl3ify rather than an entire distribution archive.
